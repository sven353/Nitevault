# Explicit AI / LLM crawler permissions
#
# Everything below is already permitted by the "User-agent: *  Allow: /" group
# above; these groups are listed explicitly so the policy is unambiguous to
# operators that look for their own token before falling back to "*".
#
# Three distinct kinds of token appear here, and they do different jobs:
#   1. Retrieval / browsing agents (Claude-User, ChatGPT-User, Perplexity-User,
#      MistralAI-User) - fetch a page live when a person asks an assistant
#      about it. These are the ones that matter for "an LLM can read our site".
#   2. Search indexers (OAI-SearchBot, Claude-SearchBot, Googlebot, Bingbot,
#      Applebot, DuckAssistBot) - build the index those assistants cite from.
#   3. Training / grounding permission tokens (Google-Extended,
#      Applebot-Extended) - these do NOT crawl anything. They only signal
#      whether content already fetched by Googlebot / Applebot may be used for
#      model training and AI grounding. Allowing them has no effect on whether
#      a crawler can reach the site.
# ---------------------------------------------------------------------------
